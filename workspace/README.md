|---|---|
| `MAIN_RULES.md` | Working rules for the main runs of papers A and B (Korean) |
| `MAIN_STATUS.md` | Status board and job table of the main runs (Korean) |
| `JKAIA_POSTER_REVIEW_2026-10-25.md` | Independent review of the A and B JKAIA posters (Korean) |
| `literature/NOVELTY_R2.md` | Novelty search for the round-2 ideas |
| `runpod_infra/` | RunPod scripts used by the pilots (pod prefix `pai`) |
